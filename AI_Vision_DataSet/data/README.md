# Instructions for Dataset

## download Real Data
For best results, download a real dataset.
Recommended: **Soil types** on Kaggle.
URL: https://www.kaggle.com/datasets/matshidiso/soil-types

## Folder Structure
Organize your data like this:

data/
  train/
    Black_Soil/
      img1.jpg
      ...
    Sand/
      img1.jpg
      ...
    Clay/
      img1.jpg
      ...
  val/
    Black_Soil/
    Sand/
    Clay/

The code is set up to automatically find these classes.
